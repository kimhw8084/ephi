# CHG-234 U2.4 · bounded Asset 360 and history

## Scope

This slice adds canonical `/ephi/assets` and `/ephi/assets/{id}` destinations
for assets represented by a supported `InvestigationProfile` in currently
authorized Episode truth. It does not create an asset master, a second
read/source/workflow authority, or an EPHI table for source observations.
Assets absent from qualified Episode truth are outside this view; the list
does not assert completeness against a company asset master.

The list uses O8 authorization before Episode-head existence/count reads,
canonical family/site/context/characteristic filters, deterministic asset-ID
tie-breaking, and the existing retained O2 query snapshots/cursors. Detail
reads compose:

- immutable O3 Episode/read revisions and known/published cutoffs;
- O5 current/as-known workflow snapshots, actions, checks, recovery, closure
  and reopen receipts;
- exact O4 `MetrologySourceBinding`, `SourceSnapshotRecord` and
  `SourceCapabilityRecord` identities;
- the bounded read-only U1 `MetrologyObservation` contract; and
- O8 current authorization on every request.

No immutable Episode revision is rewritten. Historical workflow snapshots are
labeled separately from workflow state as known at the requested cutoff.
Recorded action timing and recovery facts are observations; they do not imply
that an action caused an analytical change or recovery.

## Bounded source and comparison behavior

The configured observer must exactly match the O4 binding. The reader
requests an explicit bounded time window, then accepts observations only for
the exact asset, context, characteristic and unit when both event time and
`source_available_at` are no later than the requested cutoff. Point count,
time window, binding identity and source-row identities are included in
deterministic result identity. Raw observations remain with the source
provider and are not persisted in EPHI.

The trend draws observations as separate points, leaving missing periods as
gaps. It does not smooth, interpolate, convert units or broaden a peer
population. A two-asset descriptive comparison is available only when both
assets have exact compatible family/context/characteristic/unit identities
and the O4 binding explicitly qualifies the peer/reference population. Any
mismatch returns a bounded `BLOCKED` reason. No causal/RCA, predictive-health
or composite-health score is calculated.

Capability coverage shows effective state, O4 state, binding/provider/source,
schema/mapping, snapshot and manifest identity, source age, event/availability
times, and qualified reference/comparable identities. Missing or
non-published snapshot facts cannot appear `READY`; stale and partial source
inputs remain visibly degraded. Material/WIP context is explicitly
unavailable unless a future qualified source provides it.

## Synthetic evidence and checks

The private-style synthetic semiconductor fixture contains one primary asset
with multiple Episodes and revisions, one compatible peer, one incompatible
asset, source observations across a deliberate history gap, a future-available
observation, wrong-identity rows, and READY/STALE/PARTIAL/UNAVAILABLE O4
capability cases. It records synthetic O5 action and recovery facts. All
identities, data, policies and relationships are fictional and are not
company records.

Focused PostgreSQL 18 reference evidence is `tests.test_assets_postgresql`.
Candidate-bound desktop 1440×900 and phone 390×844 evidence, including
compatible and blocked comparison, stale capability, Episode deep links,
keyboard focus, screenshots, and clean console/page/request inventories is
in [evidence/u2/chg-234-u2.4-asset-360/qualification.json](../evidence/u2/chg-234-u2.4-asset-360/qualification.json).
The browser report is bound to a working-tree candidate based on
`main@4482233202ff2667262ff0d47ff390e72d398d3c`.

This slice is reference implementation evidence only. It makes no claim for
company asset-master completeness, real-family G02/G06, production capacity
or G10, Operations destination implementation, Port Gate/G12, or Production.
